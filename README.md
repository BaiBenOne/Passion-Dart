# Passion Dart

> Site pour passsionés de flechettes de type blog, avec quelque infos pratiques (regles des jeux les plus joué, dart finish...)


## Auteur

-Benjamin Baillet


### Sujet choisi

Site sur les flechettes/darts

### Public cible

Tout type de personnes voulant se mettre au flechette, débutant comme confirmée.



## Structure du site

| Page                 | Nom du fichier     | Description courte                      |
| -------------------- | ------------------ | --------------------------------------- |
| Page 1 - Accueil     | `accueil.html`     | Page acceuil du site                    |
| Page 2 - Régles      | `regles.html`      | regles principaux jeux                  |
| Page 3 - dart finish | `dart_finish.html` | points pour finir en 2/3 flechettes/FAQ |
| Page 4 - contact     | `contact.html`     | faux formulaire de contact              |


## Fonctionnalités

### Interactions visuelles

- Effet sur les case du tableau avec hover
- Animation bouton avec scale
- Animation de texte déffilante
- Annimation hover sur les sections de la pages acceuil


### Responsive

- La navbar deviens un menu burger
- adapter à toute tailles écran

### Accessibilité

- couleurs contrastés (score AAA)
